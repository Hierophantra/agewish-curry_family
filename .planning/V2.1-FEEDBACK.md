# v2.1 Feedback + Scope

**Captured:** 2026-05-02
**Source:** User feedback + cross-AI peer review (Claude / Gemini / Codex)
**Decision:** 15 items confirmed; phased into Phases 14–18

---

## Confirmed scope (15 items)

### User originals (6)

1. **Nav bar visual upgrade** — feels cheap; needs more substance. Active tab highlight (currently 1.25px gold underline) is too simple.
2. **Remove "Sign out"** from TopNav. (Functional sign-out can move to a small footer link if needed; not critical.)
3. **Person panel doesn't overtake the tree** — currently the panel docks within `tree-container` taking ~380px right, shrinking tree by ~40%. As tree grows down through generations, this becomes unworkable. Restructure so panel doesn't compete with tree real estate.
4. **Remove bio sections** from PersonPanel. Keep: name, dates, info rows (Born / Birthplace / Spouse / Children / Parents), photos, videos.
5. **Remove thin square box artifacts** — appears around panel name and possibly nav active tab. Likely default focus rings or button borders. Audit globally.
6. **Bigger fonts + more navy/gold color saturation** — current palette is too restrained. Bump heading and body sizes; introduce more navy/gold accents (section dividers, eyebrows in gold-deep, card borders, possibly navy/ivory section backgrounds).

### A+ adds from peer review (8)

7. **Provenance metadata model (Codex)** — add archivist fields to schemas:
   - `source` (who provided this scan / recording)
   - `circa` (boolean: approximate date)
   - `confidence` ("high" | "medium" | "low") for uncertain dates
   - `identifiedBy` (who identified people in a photo)
   - `lastVerified` (ISO date)
   These don't render visually by default; they preserve archive integrity for decades.

8. **URL-synced state (consensus pick)** — deep linking everywhere:
   - `/tree?person=william-curry` opens panel directly to William
   - `/photographs/lake-house-summers?photo=1981-lake-house-01` opens lightbox to that photo
   - `/videos/birthdays?video=grandfather-80th` opens video lightbox
   - State survives page refresh; URLs are shareable

9. **Audio as a content type (Claude + Gemini)** — `content/audio.json`, `<AudioPlayer>` component, audio attached to people / photos / collections. "Listen to the story" button. Voice carries memory in ways photos and videos cannot replicate.

10. **Archive manifest export (Gemini)** — footer-level "Download archive" → `manifest.zip` containing all `content/*.json` + a self-contained static `index.html` + all photos. Family has a portable copy that survives Next.js / Vercel / framework churn.

11. **Accessibility hardening (Claude + Codex)** — focus traps in Lightbox/PersonPanel, return-focus on close, `prefers-reduced-motion` respected by motion library, keyboard navigation of tree nodes (currently mouse-first), proper ARIA on dialogs.

12. **BlurHash placeholders (Claude + Gemini)** — build-time generated ~30-byte color blurs stored in `photos.json`. Photos crossfade from blur to focus. Smooth loading on slow connections; eliminates broken-image flash.

13. **Custom 404 + poetic empty states (Claude)** — `not-found.tsx` with branded copy + link home. Polish existing empty states so they feel intentional rather than functional. Low priority but lightweight.

14. **Slideshow / ambient mode (Claude)** — `/slideshow` route auto-advances through random photos full-screen, 8s intervals; `?collection=lake-house-summers` filters. Killer feature for eventual TV (Firestick) deployment.

### Small data fix (1)

15. **Relation labels** — normalize `family.json` `relationLabel` to: GRANDFATHER / GRANDMOTHER / FATHER / MOTHER / SON / DAUGHTER / GRANDSON / GRANDDAUGHTER. Currently William is "PATRIARCH" — change to "GRANDFATHER" per user preference. Matches the prototype.
