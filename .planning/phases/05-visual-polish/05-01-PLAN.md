    without AnimatePresence (Pitfall 4 — AnimatePresence cross-page is broken in App Router).

    ```tsx
    // app/template.tsx
    // Per D-05: re-mounts on every navigation — the App Router idiom for entry animations.
    // AnimatePresence is NOT used here (see PITFALLS.md Pitfall 4 — cross-page exit animations
    // are broken in App Router). Entry-only animation (initial + animate, no exit) is reliable.
    'use client'
    import { motion } from 'motion/react'

    export default function Template({ children }: { children: React.ReactNode }) {
      return (
        <motion.div
          initial={{ opacity: 0, y: 8 }}
          animate={{ opacity: 1, y: 0 }}
          transition={{ duration: 0.4, ease: 'easeOut' }}
        >
          {children}
        </motion.div>
      )
    }
    ```

    Duration 0.4s and y: 8 per D-05. The `ease: 'easeOut'` gives a decelerating feel —
    content arrives from below and settles, rather than linear movement. No exit animation
    is defined — this is intentional (Pitfall 4).

    After both edits, run `npm run build` to verify the build still exits 0.
