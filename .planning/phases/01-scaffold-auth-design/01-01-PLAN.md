**Step B — app/globals.css** (full replacement):

IMPORTANT token naming decision (pre-locked per planning context):
- Use `--color-muted` (NOT `--color-text-muted`) → generates class `text-muted` (no double-prefix)
- Use `--color-quiet` (NOT `--color-text-quiet`) → generates class `text-quiet`

```css
/* app/globals.css */
@import "tailwindcss";

@theme {
  /* ── AgeWish Brand Palette ── */
  /* Complete class names generated: bg-navy, text-navy, border-navy, fill-navy, etc. */
  --color-navy:      #1F2D5C;
  --color-gold:      #E8A91F;
  --color-gold-deep: #B8851A;
  --color-ivory:     #FBF9F2;
  --color-border:    #E2DFD5;
  --color-stone:     #C9C4B0;
  --color-muted:     #6B6960;
  --color-quiet:     #8B8778;

  /* ── Typography — body (Inter via CSS variable from next/font) ── */
  --font-sans: var(--font-inter), ui-sans-serif, system-ui, sans-serif;

  /* ── Typography — serif headings (Georgia fallback for v1; Cormorant in Phase 5) ── */
  --font-serif: Georgia, 'Times New Roman', serif;

  /* ── Font weights — two-weight rule: ONLY 400 and 500 ── */
  /* Defining only these two prevents font-bold/font-semibold from generating */
  --font-weight-normal: 400;
  --font-weight-medium: 500;
}

/* ── Custom utilities (Tailwind v4 @utility directive) ── */

@utility eyebrow {
  text-transform: uppercase;
  letter-spacing: 0.22em;
  font-size: var(--text-xs, 0.75rem);
  font-weight: 500;
}

@utility hairline {
  border-width: 0.5px;
  border-color: #E2DFD5;
}

@utility hairline-emphasis {
  border-width: 1.25px;
  border-color: #E2DFD5;
}

/* ── Base styles ── */
@layer base {
  html {
    font-family: var(--font-sans);
    color: #1a1a1a;
    background-color: white;
  }

  h1, h2, h3, h4, h5, h6 {
    font-family: var(--font-serif);
    font-weight: 400;
  }
}
```

**Step C — app/layout.tsx** (root layout with Inter as CSS variable):
```typescript
// app/layout.tsx
import type { Metadata } from 'next'
import { Inter } from 'next/font/google'
import './globals.css'

// Load Inter with exactly weights 400 and 500
// variable: '--font-inter' injects a CSS custom property on <html>
// so @theme { --font-sans: var(--font-inter), ... } can reference it
const inter = Inter({
  subsets: ['latin'],
  weight: ['400', '500'],
  display: 'swap',
  variable: '--font-inter',
})

export const metadata: Metadata = {
  title: 'The Curry Family',
  description: 'A private family archive.',
  robots: 'noindex, nofollow', // Private site — never index
}

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className={inter.variable}>
      <body>{children}</body>
    </html>
  )
}
```

Note: `className={inter.variable}` (not `inter.className`) — this injects `--font-inter` as a CSS variable so `@theme` can reference it. If `inter.className` were used instead, the CSS variable would not be available.
