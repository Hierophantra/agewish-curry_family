## What shipped in v2.1

v2.1 was driven by two sources: user punch list feedback (6 items) and cross-AI peer review recommendations from Claude, Gemini, and Codex (8 items + 1 data fix). All 15 confirmed scope items were delivered.

---

### Phase 14: v2.1 Visual + UX Polish

**Plans:** 14-01 (visual), 14-02 (polish + 404)

**Delivered:**
- Nav bar substance upgrade: active tab highlight, more visual weight
- Sign out removed from TopNav (simpler; sign-out in footer for edge cases)
- Person panel restructured so it no longer competes with tree real estate — panel docks as an overlay, tree keeps full width
- Bio sections removed from PersonPanel; kept: name, dates, info rows, photos, videos
- Thin square box artifacts fixed globally (default focus rings audited and removed)
- Bigger fonts, more navy/gold saturation throughout
- Relation labels normalised: GRANDFATHER/GRANDMOTHER/FATHER/MOTHER/SON/DAUGHTER (not PATRIARCH)
- Custom `not-found.tsx` with branded AgeWish copy and link home
- Polished empty states across gallery, person pages, and videos sections

---

### Phase 15: v2.1 Schema + Accessibility

**Plans:** 15-01 (provenance schema), 15-02 (accessibility hardening)

**Delivered:**
- Provenance metadata fields on PhotoSchema + PersonSchema: `source`, `circa`, `confidence`, `identifiedBy`, `lastVerified`, `scannedDate`, `originalFilename`
- Focus traps in Lightbox and PersonPanel via `useFocusTrap` hook (Phase 15 focus-trap library)
- Return-focus on modal close: focus returns to trigger element when Lightbox/panel unmounts
- `prefers-reduced-motion` respected in all motion components via `useReducedMotion()` from motion/react
- Keyboard tree navigation: arrow keys move keyboard focus between tree nodes spatially
- ARIA hardening: `aria-modal="true"`, `aria-labelledby`, `role="dialog"` on Lightbox and PersonPanel

---

### Phase 16: v2.1 Deep Linking + BlurHash

**Plans:** 16-01 (URL-synced state), 16-02 (BlurHash placeholders)

**Delivered:**
- `/tree?person=william-curry` opens PersonPanel directly (URL survives refresh, is shareable)
- `/photographs/lake-house-summers?photo=1981-lake-house-01` opens Lightbox to that photo
- `/videos/birthdays?video=grandfather-80th` opens VideoLightbox to that video
- `router.replace` used for lightbox prev/next (no browser history pollution)
- BlurHash blur-up placeholders: `blurDataUrl` field added to PhotoSchema
- `scripts/generate-blur-data.mjs` using plaiceholder + sharp generates base64 blur data
- `npm run blur` command in package.json for content authors
- Lightbox, PhotoCard, and CollectionCard all use `placeholder="blur"` when `blurDataUrl` is present

---

### Phase 17: v2.1 Audio Content Type

**Plans:** 17-01 (audio as first-class content)

**Delivered:**
- `AudioSchema` in `lib/types.ts` with full provenance fields
- `content/audio.json` with stub entries (voicemail, oral history, songs)
- Placeholder audio files in `public/audio/` (1-byte stubs for development)
- `AudioPlayer` component: native `<audio>` element with play/pause toggle, waveform indicator, metadata display
- Audio section on person detail pages: "Listen to their voice" heading with stacked `AudioPlayer` list
- `getAudio()`, `getAudioById()`, `getAudioByPersonId()` loaders in `lib/content.ts`
- Audio cross-reference validation in `validateBidirectionalRefs()`
- Audio authoring documentation in `CONTENT_AUTHORING.md`

---

### Phase 18: v2.1 Archive Export + Slideshow

**Plans:** 18-01 (archive export), 18-02 (slideshow)

**Delivered:**

**Archive export:**
- `/api/archive` route handler: generates `manifest.zip` on demand using jszip
- Zip includes all `content/*.json` files + `index.html` static viewer + all `/public/photos/*`
- `lib/archive-template.ts`: self-contained HTML viewer with embedded family data (works offline, no Next.js/Vercel needed)
- "Download the archive" link in Footer
- Archive workflow documented in `CONTENT_AUTHORING.md`

**Slideshow / ambient mode:**
- `/slideshow` route: Server Component fetches photos, passes to `SlideshowPlayer` client component
- Photos shuffled on mount for ambient randomness (different order each visit)
- 8-second auto-advance via `setInterval`
- 1.2s crossfade via `AnimatePresence` with `mode="wait"`
- `?collection=lake-house-summers` filter for single-collection playback
- Keyboard `←`/`→` for manual navigation (auto-advance continues in background)
- Controls overlay auto-hides after 3s of mouse inactivity
- Caption + date always visible at bottom (informational, not purely decorative)
- `prefers-reduced-motion` respected: crossfade collapses to instant
- `blurDataUrl` placeholder flows naturally from Phase 16
- Empty state when no photos are available
- "Play ambient slideshow →" links from `/photographs` and collection detail pages
- `fixed inset-0 z-50` covers TopNav/Footer without requiring a special layout wrapper
